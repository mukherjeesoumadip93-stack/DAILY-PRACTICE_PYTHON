# Basic Python 🐍

Welcome to the **Basic Python** repository! This project contains beginner-friendly Python programs and examples designed to help you understand the fundamentals of Python programming.

## 📚 Topics Covered

* Python Introduction
* Variables and Data Types
* Operators
* Conditional Statements (if, elif, else)
* Loops (for and while)
* Functions
* Lists, Tuples, Sets, and Dictionaries
* String Manipulation
* File Handling
* Exception Handling
* Basic Object-Oriented Programming

## 🎯 Purpose

The main goal of this repository is to practice Python programming, improve problem-solving skills, and build a strong foundation in Python.

## 🛠️ Technologies Used

* Python 3.x
* VS Code / PyCharm

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/mukherjeesoumadip93-stack/DAILY-PRACTICE_PYTHON.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Basic-Python
   ```

3. Run a Python file:

   ```bash
   python filename.py
   ```
